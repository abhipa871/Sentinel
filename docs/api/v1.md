# API v1

The FastAPI application exposes asynchronous scan creation and immutable result reads.

- `POST /v1/repositories/scan` starts Phase 0 through the requested module.
- `GET /v1/scans/{id}` returns state, pinned commit, coverage, and errors.
- `GET /v1/scans/{id}/graph` returns file/asset nodes and evidenced edges.
- `GET /v1/scans/{id}/potential-vulnerabilities` returns Module I candidates.
- `GET /v1/scans/{id}/findings` returns Module II outcomes including abstentions/refutations.
- `GET /v1/scans/{id}/plans` returns Module III proposals and solver result.
- `POST /v1/scans/{id}/proposals/{proposal_id}/decisions` records one immutable decision.
- `GET /v1/audit-events` returns the local append-only approval view.

Mutations require `Idempotency-Key`, `X-Sentinel-Actor`, and `X-Sentinel-Role`. The development
header adapter represents the production OIDC/GitHub session boundary; deployments must replace it
with an authenticated principal provider.
