# Sentinel hackathon demo

The interface is Amitr24's original HackPrinceton website from commit `d16ac1d`. Its layout,
visual language, finding map, detail drawer, replay interaction, and ChatOverflow flow remain the
baseline. SENTINEL adds only the Module I table and the two requested graph views.

Open `index.html` in a browser with `assets-data.js`, `module1-data.js`, and `graphs-data.js` beside
it, or serve this directory with `python -m http.server 8080`.

The displayed data is generated from `artifacts/crapi-full-v7.json`: 58 Module I potential
candidates, 58 Module II dispositions, and exactly 24 `strongly_supported` high-evidence findings.
No inconclusive result is relabeled as supported. Run demo scan replays this saved result; it does
not invoke a live model or scan. ChatOverflow creates a defensive lesson draft for manual sharing.

Regenerate the finding and Module I datasets with:

```powershell
python scripts/build_website_data.py artifacts/crapi-full-v7.json
```

## Graph views

The additive views are available beside Findings and can be opened directly with
`index.html#module1`, `index.html#repo`, and `index.html#vuln`:

- **Module I table**: every potential candidate from the same saved run, with its investigation
  priority, evidence counts, and unmodified Module II disposition. The 24 high-evidence rows are
  explicitly distinguished from inconclusive, refuted, and not-analyzed rows.

- **Repo graph**: a sample of the repository file graph per service (imports and URL routing
  between files), taken from a saved scan. Files with candidates are highlighted.
- **Vulnerability graph**: a subset of the packaged vulnerability knowledge graph around the CWEs
  shown in Findings: their parent weaknesses, the OWASP API Security Top 10 risks that reference
  them, and up to two CAPEC attack patterns each. Relations are the catalogs' own.

Graph data lives in `graphs-data.js`, generated by
`python scripts/build_website_graphs.py artifacts/crapi-full-v7.json`. The generator reads the
high-evidence CWE set from `assets-data.js` and never changes the finding dataset.
