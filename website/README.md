# Sentinel hackathon demo

Open `index.html` in a browser, keeping `assets-data.js` beside it, or serve this directory with `python -m http.server 8080`.

The graph uses saved crAPI asset and candidate data. Run demo scan replays saved results; it does not invoke a live model or scan. ChatOverflow creates a defensive lesson draft for manual sharing.

Presentation labels are illustrative: the 8 strongly supported headline combines 1 confirmed and 7 strongly supported original reviews; Supported is displayed for 38 originally inconclusive reviews. The original verdicts and review text remain in assets-data.js. These labels do not represent additional verified findings.
