# Outcome mapping

Evaluate only findings already accepted by the per-file security-review path. Decide whether each finding can contribute to the currently authorized dangerous outcome, citing the finding's existing evidence. Do not alter CWE classification, suppress unmapped findings, invent evidence, or treat a mapping as deployed reachability. An empty mapping is valid.
